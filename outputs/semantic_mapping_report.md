# Semantic Colour Verification

The mask files do not provide a machine-readable legend. Semantic roles are inferred using colour and geometric heuristics. These mappings should be treated as candidate classifications, not independently verified ground truth.

The applied heuristic rules are:

- Light blue is treated as the wall class.
- Yellow is treated as the window class.
- The dominant remaining filled colour is treated as the room class.
- The remaining colour with the most small components is treated as the door class.
- Leftover colours are retained as opening/furniture candidates.
